# &#x09;  Random Number Tool

This project is a simple C++ program that provides several random number utilities through a menu system. The user can generate a random number, play a guessing game, compare two random numbers, or calculate the average of two random numbers.



Features

Generate a random number  

Produces a random integer using the C standard library and current time as the seed.



Guessing Game  

The program selects a random number between 1 and 10,000. The user guesses until correct. The program reports whether each guess is too high or too low and displays the total number of attempts.



Compare Two Random Numbers  

Generates two random numbers and reports which one is greater or if they are equal.



Random Number Average  

Generates two random numbers and calculates their average.



#### &#x09;		How to Run

Compile the program with a C++ compiler such as cl.exe, g++, or clang++.



Run the compiled executable.



Choose an option from the menu.



Follow the prompts for each tool.



#### &#x09;	       Requirements

C++ compiler



Standard library support



Windows or any platform with a compatible compiler.
